# BrandOn Studio: team workspace

The internal tool where Brand On's PMs, designers and videographers run every project.

- `src/` the app, plain JavaScript and CSS
- `build.py` builds it into one file: `python build.py` for your hosting (`public/index.html`), `python build.py claude` for the Claude page
- `public/` what the website serves: the app, `config.js`, icons and the home-screen manifest
- `supabase/` database setup and the two Telegram functions
- `SETUP.md` step-by-step setup, about 30 minutes

Copy rules: Mongolian by default with an English switch, no em dashes anywhere.
